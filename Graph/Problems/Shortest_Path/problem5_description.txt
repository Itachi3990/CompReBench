Evening Shuttle Corridor

A shuttle operator is asked to move passengers from one station to another across a graph of weighted links. The network contains quiet side streets, elevated connectors, and a few longer roads that bypass traffic. The start station and end station are fixed, and the aim is to find the least expensive way to connect them.

The operator can stop at intermediate stations if that creates a cheaper route overall, but the final path must still begin at the origin and end at the destination. The fact that a route uses more edges does not automatically make it worse. In this setting, the lowest total weight matters more than the number of hops. The correct solution should evaluate the graph globally and choose the cheapest valid route between the two endpoints.
