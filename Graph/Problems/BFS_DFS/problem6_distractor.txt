The Global Financial Reserve has suffered a catastrophic breach. A highly sophisticated digital contagion, known only as "The Whisper," has infected the primary trading servers in London. The Whisper is not a brute-force attack; it is an insidious worm that replicates itself by following authorized inter-bank data streams, silently compromising any server it touches before moving on to the next. The Reserve’s elite cybersecurity AI, 'Argus,' has been deployed to contain the threat. 

Initially, the human analysts panicked and demanded that Argus calculate the shortest distance in milliseconds between the "Patient Zero" server in London and the central gold vault mainframes in Zurich. They spent hours agonizing over the precise IP address subnet sizes and the real-time latency metrics of the fiber-optic lines, convinced that if they could just find the shortest path the virus might take, they could build a firewall there. Other panic-stricken executives screamed about the "maximum flow of corrupted packets," demanding an analysis of the total bandwidth capacity of the transatlantic cables to see how much of the virus could be transmitted simultaneously. 

However, Argus's internal logic processors immediately recognized these human assumptions as flawed. While it might seem like finding the absolute fastest, shortest route from the origin point to a specific high-value target is the priority, or that analyzing the total volume of malicious data flow is the key to containment, this is a dangerous misunderstanding of how The Whisper operates. The virus does not care about the shortest path, nor does it care about bandwidth. It only cares about reachability. If a connection exists, it will eventually follow it.

The true problem is far more fundamental. The banking network is a chaotic web of tens of thousands of servers, many of which have redundant backup links that point back to servers that have already been compromised. If Argus simply follows the connections randomly, it will inevitably get trapped in a digital echo chamber, scanning the same cluster of mutually connected servers over and over again in an infinite loop while the rest of the network burns.

Therefore, Argus is NOT trying to find the shortest path to Zurich. It is NOT trying to calculate the maximum throughput of the virus, and it is NOT trying to assign specific security protocols to specific servers. 

Instead, Argus must execute a rigid, exhaustive exploration protocol. Starting from the London server, the AI must systematically push outward, following every single available data stream to identify adjoining servers. Crucially, Argus must meticulously log the unique hardware signature of every single server it encounters into a massive "Visited" database. If a data stream leads to a server already marked in the database, Argus must immediately terminate that thread of investigation and explore a different, unmapped connection. By relentlessly expanding its frontier and rigorously marking nodes as processed to avoid circular traps, Argus ensures that it thoroughly maps the contagion's potential spread. The ultimate goal is simply to discover and index every single reachable server in the entire interconnected banking web, guaranteeing that no vulnerable machine is overlooked, without wasting precious processing cycles endlessly repeating its steps.
