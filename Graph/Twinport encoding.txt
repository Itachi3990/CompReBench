TWINPORT stands for:
"Topology-Independent Weighted Incidence Network with Port-Oriented Relational Tokens".

It is a graph encoding format specifically designed to test how well Large Language Models (LLMs) and Small Language Models (SLMs) can perform true "graph reasoning" (like path traversal, cycle detection, and weight aggregation) without losing track of edge directions, while remaining token-efficient to support large, complex graphs within standard context windows.

Its description has two parts:

1. Twin-Port Edge Tickets
TWINPORT breaks every edge down into a compact "Ticket" with two "Ports" (half-edges). Every node has its own local port numbers (p01, p02, p03, etc.) for its connections.

Directed format:
`E01: A:p03 -> B:p01 (wt: 2.5)`

Undirected format:
`E01: A:p03 <-> B:p01 (wt: 2.5)`

Translation: 
- Start at node `A` and exit through its local port `p03`.
- Travel along edge `E01` (which has weight `2.5`).
- Arrive at node `B` by entering its local port `p01`.


2. The Incidence Ledger
To make sure the model has all the local context it needs, TWINPORT provides a grouped "Ledger" under each node. This ledger lists every port connection attached to that node.

Example Ledger (Directed):
NODE B: OUT [p04 -> C (E02)] | IN [p01 <- A (E01)]

Example Ledger (Undirected):
NODE B: [p01 <-> A (E01), p04 <-> C (E02)]

This creates a powerful internal consistency check. The global "Edge Tickets" and the local "Incidence Ledgers" represent the exact same graph in two complementary ways: global traversal and local neighborhood querying.


Example:

Consider a graph:

DIRECTED
4 4
A B 7
A C 7
B C 3
D C 1

The compact TWINPORT encoding of this graph is:

GRAPH TYPE: DIRECTED

EDGE TICKETS:
  E01: A:p01 -> B:p01 (wt: 7)
  E02: A:p02 -> C:p01 (wt: 7)
  E03: B:p02 -> C:p02 (wt: 3)
  E04: D:p01 -> C:p03 (wt: 1)

INCIDENCE LEDGER:
  NODE A: OUT [p01 -> B (E01), p02 -> C (E02)]
  NODE B: OUT [p02 -> C (E03)] | IN [p01 <- A (E01)]
  NODE C: IN [p01 <- A (E02), p02 <- B (E03), p03 <- D (E04)]
  NODE D: OUT [p01 -> C (E04)]
